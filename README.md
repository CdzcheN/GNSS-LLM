## 1. 项目概述

### 1.1 一句话定位

在 u-blox F9P 接收机**状态观测层**（PVT / C/N₀ / 残差 / AGC / RAWX，1 Hz，KB/s 级）构建**深度时序模型**，实现正常（clean）/ 欺骗（spoofing）/ 压制干扰（jamming）**三态协同检测**，并满足轻量可部署约束。

### 1.2 项目目标（对应申报书"研究内容—主要目标"）

| 目标编号 | 目标内容 | 可验证指标 |
|---|---|---|
| G1 | 三态判别：clean/spoofing/jamming 协同检测 | macro-F1 ≥ 0.90（或按基线实测定），干扰类（仅 481 s）P/R 单独报告 |
| G2 | 跨星座跨频多源特征融合 | 模态消融证明 B（AGC/频谱）、C（RAWX）相对 A 的增量贡献 |
| G3 | 类别不平衡与少样本鲁棒检测 | 干扰类召回率显著优于不加权基线；leave-one-event-out 稳健 |
| G4 | 轻量可部署 | 参数量 < 10⁶；INT8 量化后精度损失 < 1%；单秒推理实测报告 |

### 1.3 范围边界

**做**：状态观测层三态检测与分类、多模态融合、不平衡处理、轻量化部署预算实测。
**不做**：原始 I/Q 级检测；全复数域模型（仅二期作为可选探索）；跨接收机硬件适配。

## 3. 需求规格

### 3.1 功能需求（FR）

| ID | 需求 | 描述 | 验收口径 |
|---|---|---|---|
| FR1 | 数据解析与特征构建 | 解析 processed JSON（一期模态 A）与 Raw data UBX JSON（二期模态 B/C），三流按时间戳排序取交集，输出统一 schema 特征表 | 输出行数与时间覆盖对齐；缺秒带 `miss_mask`；一期列与现有 CSV 可抽样对齐 |
| FR2 | 三态判别模型 | 多模态分组编码 → 融合 → 时序编码器 → 三分类头（softmax 0/1/2），支持窗口化推理 | 1221 后 30% 测试集输出混淆矩阵、macro-F1 |
| FR3 | 不平衡鲁棒训练 | 类别加权 CE / focal loss + 数据增强/重采样；干扰类单独评估 | 干扰类 recall 显著高于等权基线 |
| FR4 | 评估与泛化验证 | 逐秒级（AUC-ROC/AUC-PR/F1/FPR）+ 事件级（检出率/检测延迟/误报事件数）+ leave-one-event-out | 两级指标同时报告；泛化折结果稳定性 |
| FR5 | 轻量部署原型 | 模型蒸馏/剪枝/INT8 量化，输出推理时延、内存、参数量实测 | 达成 G4 指标；给出 MCU/低端 SoC 可行性结论 |

### 3.2 非功能需求（NFR）

| ID | 需求 | 指标 |
|---|---|---|
| NFR1 | 可复现 | 固定 `seed=42`；划分文件 `splits/*.csv` 入库；`requirements.txt` 锁版本 |
| NFR2 | 轻量 | 参数量 < 10⁶；INT8 权重 < 1 MB；激活内存 KB 级 |
| NFR3 | 数据规范 | 数据大文件不入库，经 `config.yaml` 路径引用；实验一行一记录入 `experiments_log.csv` |
| NFR4 | 无泄漏 | 训练/验证/测试时间不重叠；scaler 仅 fit 训练集 |

### 4.3 特征结构（112 列 = 模态 A，108 数值特征）

`Timestamp, Day, Hour`（3 元数据）＋ `hAcc,vAcc,tAcc,clkB,clkD,gSpeed,pDOP,tDOP,hDOP`（9 PVT）＋ `NumSats,AvgCNO,MaxRes`（3 全局）＋ 32 PRN × `CNO/Res/Elev`（96 卫星指纹）＋ `Label`。

二期扩展：模态 B（AGC/频谱约 22 维 + 可选 128 维谱）、模态 C（RAWX 定长化 206 维）；并补 `StdCNO、AvgRes` 两个一期缺口列。详见 `特征说明.md`。

### 4.4 已知数据质量要点（开发时必须处理）

1. `recordTime` 非严格有序 → 提取时按时间戳重排；
2. 12–15 缺 1,239 s → 前向填充或 `miss_mask` 掩码训练；
3. 卫星列稀疏（78–92% 为 0）→ `sat_mask = (CNO > 0.5)` 显式掩码；
4. 1221 相对 12–15 为分布外（不同日期/场景）→ 评估时声明为泛化测试；
5. 干扰类仅 481 s → 事件级评估为主，不单独拟合干扰类阈值。

## 6. 模块详细设计要点

### 6.1 M1 数据解析（对应申报书"思路方法"第 1 步）

- **职责**：读取三流 JSON，按 `recordTime` 排序取交集，输出对齐后的特征帧。
- **一期**：复用 `GNSSInterfer/ReadDataCombineObsSatPvt*.py`（当前 CSV 生成脚本）。
- **二期**：新写统一管线 `extract_features.py`，合并现有两脚本逻辑，修复 recordTime 排序问题；MON-SPAN 提 `pga_01/02` + 频谱统计；RXM-RAWX 按 32 槽位定长化；输出 parquet（模态 A+B+C）。
- **验收**：单测用小样例 JSON fixture；全量提取行数与一期 CSV 对齐，抽样比对模态 A 列。

### 6.2 M2 特征工程（对应"思路方法"第 2–3 步）

- 输入：M1 输出的特征帧；输出：窗口化张量 `B×W×D` + 辅助掩码。
- 关键点：`sat_mask`（32 维）、`miss_mask`（缺秒）、`clkB/clkD` 一阶差分、逐特征 z-score（fit 于 12–13 训练集，1221 复用同一 scaler）。
- 窗口：W=60 s 默认，敏感性另测 10/30/120。
- 补缺口：二期补 `StdCNO、AvgRes`（与 AvgCNO/MaxRes 同源，成本极低）。

### 6.3 M3 模型（对应 IN1/IN2）

- 结构遵循 `GNSS-Anomaly-Model-Architecture.md`：模态分组编码 → 中间融合（concat 主推）→ 时序编码器 → 双任务头。
- 时序编码器三选一：**LSTM（主推，hidden=64 双层）** / TemporalCNN / 小 Transformer；申报书提及的 iTransformer/TFT/PatchTST 作为**二期对比项**加入长窗口实验，不进入默认轻量路线。
- 参数预算：融合 + LSTM(64) + 双头 ≈ 2×10⁵，满足 NFR2。

### 6.4 M4 训练（对应 IN3）

- 无监督：12–15 训练掩码感知 LSTM-AE，重建误差 → 分模态异常分数。
- 监督：1221 前 70% 训练分类头，后 30% 测试；类别加权 CE（正常 1.0 / 欺骗 ≈3.9 / 干扰 ≈70）或 focal loss（γ=2）。
- 半监督：12–15 预训练 → 1221 微调分类头（可选，缓解标注少与不平衡）。
- 训练配置、早停、正则见 Model-Architecture §8。

### 6.5 M5 评估（对应"思路方法"第 6 步）

- 逐秒级：AUC-ROC / AUC-PR / 最优阈值 F1 / 15 日 FPR；
- 事件级：检出率 / 检测延迟 / 误报事件数（告警合并 30 s）；
- 泛化：leave-one-event-out（按 1221 的 19 个欺骗区间 + 10 个干扰区间留出）；
- 消融：A / A+B / A+C / A+B+C；特征选择（递归剔除 / L1 稀疏）；SHAP 可解释性。

### 6.6 M6 部署（对应 G4 / FR5）

- 测量：参数量、单秒推理时延（PC + 嵌入式对标）、内存占用；
- 优化：训练后 INT8 量化（精度损失 < 1% 时采用）、必要时蒸馏；
- 输出：部署预算表 + MCU/低端 SoC 可行性结论。

## 11. 开发约定（工程规范）

1. 所有实验配置、指标、图路径、结论写一行 `experiments_log.csv`；
2. 评估只用 `splits/` 预定义时间戳，禁止脚本内随机切分；
3. 训练/测试时间不重叠；scaler 只 fit 训练集；
4. 数据大文件不入库，经 `config.yaml` 引用；标签与划分必须入库；
5. 负面结果（如复数域探索无收益）如实归档，论文中作为讨论素材。
