# GNSS 多特征自适应干扰监测系统

> 面向动态 GNSS 环境的多源感知、智能策略选择与深度时序协同检测系统

## 1. 项目简介
本项目面向 GNSS 欺骗（Spoofing）与压制干扰（Jamming）监测需求，基于 **多源 GNSS 状态观测数据、上下文状态建模、智能体动态策略选择和多策略协同检测**，构建可扩展的自适应干扰监测系统。项目不局限于使用单一固定检测模型，而是根据当前 GNSS 环境状态动态选择合适的检测策略，并在必要时调用多个检测器进行交叉验证，最终形成结构化检测结果。系统进一步引入大语言模型（LLM），用于对已经完成检测的异常事件进行**日志总结与信息表达**，生成面向人员的事件摘要和监测报告。

> **核心原则：**
>
> **Agent 负责决策，Detector 负责检测，Fusion 负责判定，LLM 负责总结。**

## 3. 项目主要功能
- **多源 GNSS 数据处理：** 支持 MON-SPAN、RXM-RAWX、NAV-PVT、NAV-DOP、NAV-SAT、C/N0、AGC 以及频谱及相关统计特征；完成数据解析、时间对齐、缺失处理、特征提取和滑动窗口构建。
- **GNSS 多特征联合建模：** 综合利用信号质量特征、频谱特征、卫星状态特征、伪距/载波/多普勒观测、PVT/DOP 导航解算特征和历史时序信息，形成 GNSS 环境上下文表示。
- **动态检测策略选择：** 根据当前 GNSS 环境状态、数据质量、历史检测结果、检测器适用性和检测计算开销，动态选择和组合检测策略。
- **深度时序检测：** 提供基于多变量时间序列的深度检测模型，当前以 LSTM、TemporalCNN、小型 Transformer 为主要模型路线，支持 Normal / Spoofing / Jamming 三态识别。
- **多策略协同检测：** 将不同信息来源、不同计算成本和不同物理依据的检测器统一封装，通过置信度和检测证据进行结果融合，提高复杂环境下的检测能力。
- **LLM 日志总结：** LLM 不参与底层 GNSS 异常判定，仅读取结构化事件日志，并生成异常事件摘要、检测过程总结、关键异常特征说明和面向人员的监测报告，从而实现：

> **结构化检测结果 → 自然语言信息表达**

## 4. 检测状态
当前主要支持：

| 状态         | 含义        |
| ---------- | --------- |
| `Normal`   | GNSS 正常状态 |
| `Spoofing` | GNSS 欺骗   |
| `Jamming`  | GNSS 压制干扰 |

系统同时支持事件级状态管理：`NORMAL → SUSPECTED → CONFIRMED → ONGOING → RECOVERED`。

## 6. 数据与实验
项目使用 GNSS 多星座、多频、多观测数据开展实验，重点覆盖正常 GNSS 场景、欺骗攻击场景和压制干扰场景。实验重点关注 Macro-F1、Precision / Recall / F1、AUC-ROC / AUC-PR、Jamming Recall、事件检出率、检测时延、误报事件数、跨事件泛化能力、策略调用次数和计算开销。采用**时间级和事件级数据划分**，避免连续时间序列随机划分造成数据泄漏。

## 7. 实验路线
项目采用逐级对比方式：

```text
Baseline-1 固定阈值检测 → Baseline-2 固定规则多特征融合 → Baseline-3 静态 ML / DL → Method-1 上下文感知动态策略选择 → Method-2 Agent 多策略协同
```

主要通过对比和消融实验验证：多源特征的贡献；上下文建模的贡献；动态策略选择的贡献；Agent 策略编排的贡献；多策略融合的贡献；深度时序检测器的贡献。

## 9. 项目特点
- **多源融合：** 从单一指标检测扩展到频谱、信号质量、卫星状态、原始观测和导航解算等多源信息联合分析。
- **动态检测：** 不是所有场景都使用相同检测流程，而是根据当前 GNSS 环境动态选择检测策略。
- **Agent 协同：** 智能体作为策略编排器，通过标准化工具接口调用底层检测器，而不是直接替代检测算法。
- **深度时序：** 利用时间窗口建模 GNSS 状态变化过程，重点处理复杂、多变量和高不确定性场景。
- **LLM 信息表达：** 将结构化异常事件自动转换为可读的日志摘要和监测报告，提高系统的信息呈现和运维效率。
- **可扩展架构：** 检测器、策略选择器和 LLM 均采用模块化设计，便于后续增加新的检测算法、策略和模型。

## 10. 项目运行流程
典型运行流程：数据输入 → 数据解析 → 特征提取 → Context 构建 → Agent 选择策略 → Detector 执行 → 结果融合 → 事件管理 → 实时告警 → LLM 日志总结 → 监测报告。

## 11. 开发阶段
当前项目主要按照以下阶段推进：数据处理 → 基础检测器 → 深度时序模型 → Context 建模 → 检测策略库 → Agent 动态策略选择 → 多策略融合 → 事件管理 → LLM 日志总结 → 系统集成与部署。

## 12. 项目目标
最终形成一个完整的 GNSS 自适应干扰监测闭环：

> **多源感知 → 上下文理解 → 智能决策 → 协同检测 → 结果融合 → 事件管理 → LLM总结 → 信息上报**

项目最终成果包括：GNSS 多源数据处理模块；检测策略库；深度时序检测模型；GNSS Context 模块；Agent 动态策略选择模块；多策略结果融合模块；异常事件管理模块；LLM 日志总结模块；GNSS 自适应干扰监测系统原型。
